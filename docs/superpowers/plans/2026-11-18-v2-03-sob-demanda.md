# V2 · Plano 3 — Cortes sob demanda (link → melhores momentos → #aprovação)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O admin cola `link [instrução]` no canal de links; o bot analisa o vídeo gravado (YouTube, VOD da Twitch ou da Kick), escolhe os melhores momentos, recorta em fim de frase e manda cada corte, já avaliado pela IA, para o `#aprovação`.

**Architecture:** Um `OnDemandRunner` processa uma fila de *jobs* (tabela `jobs`), um por vez, em etapas que salvam o resultado em `data/jobs/<id>/` (retomável após reinício): metadados → áudio → transcrição (Groq, em pedaços) → sinais (volume, "mais repetidos" do YouTube, chat do YouTube) → picos → IA de texto escolhe os assuntos → bordas em fim de frase → baixa só os trechos. Cada trecho vira um `Candidate` (`source="ondemand"`) já com `raw.mp4`, transcrição e legenda; a partir daí o **pipeline da V1 avalia** e o **#aprovação do Plano 1** cuida do resto. Séries "Parte N" e layout de podcast ficam no Plano 4 — aqui todo corte tem no máximo 65 s.

**Tech Stack:** Python 3.12, yt-dlp, ffmpeg, numpy, Groq Whisper, Gemini/Claude (texto), discord.py 2.x, SQLite, pytest.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-11-17-v2-discord-painel-design.md` §5 (fluxo), §9 (dados), §12 (testes).
- Entrada: **mensagem colada** no canal `gerar-clipes` (ID em `DISCORD_LINKS_CHANNEL_ID`), só do admin, formato `<url> [instrução até 500 caracteres]`. Precisa do **Message Content Intent** ligado no Developer Portal; se não estiver, o bot loga o aviso e segue funcionando sem ler mensagens.
- Limite: `ONDEMAND_MAX_HOURS` (padrão 4). Um job por vez (FIFO). Live em andamento → recusa com "live em andamento ainda não é suportada (V2.1)".
- Sinais (1 ponto por segundo, normalizados 0–1 por percentis p25–p99): pesos `heatmap 0.45`, `chat 0.35`, `loudness 0.20`, renormalizados quando falta algum; bônus `0.15` quando ≥ 2 sinais passam de 0,5 no mesmo segundo. Chat só do YouTube neste plano (Twitch GraphQL fica para depois).
- Picos: média móvel de 5 s, até 20 picos, ≥ 90 s entre eles.
- IA de texto: uma chamada por vídeo; janela de transcrição por pico: 150 s antes a 90 s depois.
- Bordas: início em começo de frase e fim em fim de frase (`.?!`, sem contar reticências) ou pausa ≥ 0,5 s, dentro de ±8 s do que a IA pediu; nunca no meio de palavra; ≥ 6 s antes do pico e ≥ 3 s depois; o fim se estende sobre risada/aplauso (volume > base + 3 dB) até 6 s, sem invadir a próxima palavra; duração entre 15 s e 65 s (acima disso, o maior trecho ≤ 65 s em volta do pico).
- Download dos trechos: `yt-dlp --download-sections "*ini-fim" --force-keyframes-at-cuts`, até 1080p.
- Candidatos sob demanda: `source="ondemand"`, `rank=1000`, nunca expiram no pipeline; card no `#aprovação` com origem `🔗 <título> · <m:ss>`.
- Arquivos do job (`data/jobs/<id>/`) são apagados quando o job termina (ok ou falha); os cortes ficam em `data/media/<candidate_id>/` como os da V1.
- Textos em português do Brasil. Testes: `.venv/Scripts/python.exe -m pytest -q` — a suíte inteira passa ao fim de cada tarefa. Testes sem rede (comandos e APIs injetados).

```python
    _JOB_FIELDS = {"state", "step", "progress", "title", "thread_id", "status_message_id",
                   "error"}

    def create_job(self, url: str, instructions: str, channel_id: int | None,
                   message_id: int | None) -> int:
        now = utcnow().isoformat()
        cur = self.conn.execute(
            "INSERT INTO jobs (url, instructions, state, channel_id, message_id, created_at,"
            " updated_at) VALUES (?,?,?,?,?,?,?)",
            (url, instructions, "queued", channel_id, message_id, now, now))
        self.conn.commit()
        return int(cur.lastrowid)

    def get_job(self, job_id: int) -> dict | None:
        row = self.conn.execute("SELECT * FROM jobs WHERE id=?", (job_id,)).fetchone()
        return dict(row) if row else None

    def update_job(self, job_id: int, **fields) -> None:
        bad = set(fields) - self._JOB_FIELDS
        if bad:
            raise ValueError(f"campos inválidos: {bad}")
        fields["updated_at"] = utcnow().isoformat()
        sets = ",".join(f"{k}=?" for k in fields)
        self.conn.execute(f"UPDATE jobs SET {sets} WHERE id=?", [*fields.values(), job_id])
        self.conn.commit()

    def next_job(self) -> dict | None:
        row = self.conn.execute(
            "SELECT * FROM jobs WHERE state='queued' ORDER BY id LIMIT 1").fetchone()
        return dict(row) if row else None

    def jobs_in(self, states: list[str]) -> list[dict]:
        marks = ",".join("?" * len(states))
        rows = self.conn.execute(
            f"SELECT * FROM jobs WHERE state IN ({marks}) ORDER BY id", states).fetchall()
        return [dict(r) for r in rows]

    def reset_running_jobs(self) -> int:
        cur = self.conn.execute("UPDATE jobs SET state='queued' WHERE state='running'")
        self.conn.commit()
        return cur.rowcount

    def job_candidates(self, job_id: int) -> list[Candidate]:
        rows = self.conn.execute(
            "SELECT * FROM candidates WHERE job_id=? ORDER BY id", (job_id,)).fetchall()
        return [_from_row(r) for r in rows]
```

```python
"""Entrada do sob demanda: metadados, áudio, trechos e chat (yt-dlp)."""
from __future__ import annotations

import json
import logging
import re
from dataclasses import dataclass
from pathlib import Path
from typing import Iterable

from ..processing.ffmpeg import MediaError, run

log = logging.getLogger(__name__)

REACTION = re.compile(r"(k{3,}|rs{2,}|hah|hue|\bmds\b|pqp|caralho|nossa|😂|🤣|\blul\b|kekw|"
                      r"omegalul)", re.IGNORECASE)


@dataclass
class VideoMeta:
    url: str
    title: str
    channel: str
    platform: str  # youtube | twitch | kick | outro
    duration: float
    is_live: bool
    heatmap: list[dict] | None
    video_id: str


def parse_metadata(info: dict, url: str) -> VideoMeta:
    extractor = (info.get("extractor_key") or info.get("extractor") or "").lower()
    platform = next((p for p in ("youtube", "twitch", "kick") if p in extractor), "outro")
    channel = info.get("channel") or info.get("uploader") or info.get("uploader_id") or "?"
    return VideoMeta(url=url, title=info.get("title") or "", channel=str(channel),
                     platform=platform, duration=float(info.get("duration") or 0),
                     is_live=bool(info.get("is_live")), heatmap=info.get("heatmap") or None,
                     video_id=str(info.get("id") or ""))


async def probe(url: str, run=run) -> VideoMeta:
    out = await run("yt-dlp", "-J", "--no-playlist", "--no-warnings", url, timeout=120)
    return parse_metadata(json.loads(out), url)


async def download_audio(url: str, dest: Path, run=run) -> Path:
    """Só o áudio, já em MP3 mono 16 kHz 48 kbps (o formato que a transcrição usa)."""
    dest.parent.mkdir(parents=True, exist_ok=True)
    await run("yt-dlp", "--no-playlist", "--quiet", "-f", "bestaudio/best", "-x",
              "--audio-format", "mp3", "--postprocessor-args",
              "ffmpeg:-ac 1 -ar 16000 -b:a 48k",
              "-o", str(dest.with_suffix(".%(ext)s")), url, timeout=3600)
    out = dest.with_suffix(".mp3")
    if not out.exists():
        raise MediaError("download do áudio não gerou arquivo")
    return out


async def download_section(url: str, start: float, end: float, dest: Path, run=run) -> Path:
    """Baixa só o trecho [start, end] (em segundos), até 1080p."""
    dest.parent.mkdir(parents=True, exist_ok=True)
    await run("yt-dlp", "--no-playlist", "--quiet",
              "-f", "bv*[height<=1080]+ba/b[height<=1080]/best",
              "--download-sections", f"*{start:.2f}-{end:.2f}", "--force-keyframes-at-cuts",
              "--merge-output-format", "mp4", "-o", str(dest), url, timeout=900)
    if not dest.exists():
        raise MediaError("download do trecho não gerou arquivo")
    return dest


def _message_text(action: dict) -> str:
    parts = []
    for a in action.get("actions", []):
        renderer = (a.get("addChatItemAction", {}).get("item", {})
                    .get("liveChatTextMessageRenderer", {}))
        for run_ in renderer.get("message", {}).get("runs", []):
            parts.append(run_.get("text") or run_.get("emoji", {}).get("shortcuts", [""])[0])
    return " ".join(p for p in parts if p)


def parse_live_chat(lines: Iterable[str]) -> list[float]:
    """Replay do chat do YouTube (uma linha JSON por item) → segundos das reações."""
    times = []
    for line in lines:
        try:
            action = json.loads(line).get("replayChatItemAction", {})
            ms = int(action.get("videoOffsetTimeMsec", 0))
        except (ValueError, AttributeError):
            continue
        if REACTION.search(_message_text(action)):
            times.append(ms / 1000)
    return times


async def fetch_youtube_chat(url: str, work_dir: Path, run=run) -> list[float]:
    """Chat do replay (só YouTube). Sem chat ou com erro: lista vazia (o sinal é opcional)."""
    try:
        await run("yt-dlp", "--no-playlist", "--quiet", "--skip-download", "--write-subs",
                  "--sub-langs", "live_chat", "-o", str(work_dir / "chat"), url, timeout=1800)
        path = work_dir / "chat.live_chat.json"
        if not path.exists():
            return []
        with path.open(encoding="utf-8", errors="ignore") as f:
            return parse_live_chat(f)
    except Exception as e:
        log.info("chat do replay indisponível: %s", e)
        return []
```

```python
"""Transcrição de vídeos longos: o áudio vai em pedaços (limite de 25 MB do Groq)."""
from __future__ import annotations

import json
from collections import Counter
from pathlib import Path

from ..processing.ffmpeg import run
from ..processing.subtitles import words_from_segments
from ..processing.transcribe import Transcript, transcribe

CHUNK_S = 1200  # 20 min a 48 kbps ≈ 7 MB


async def split_audio(src: Path, out_dir: Path, chunk_s: int = CHUNK_S, run=run) -> list[Path]:
    out_dir.mkdir(parents=True, exist_ok=True)
    for old in out_dir.glob("part_*.mp3"):
        old.unlink()
    await run("ffmpeg", "-y", "-i", str(src), "-f", "segment", "-segment_time", str(chunk_s),
              "-c", "copy", str(out_dir / "part_%03d.mp3"), timeout=600)
    return sorted(out_dir.glob("part_*.mp3"))


async def transcribe_long(audio: Path, groq_key: str, http, work_dir: Path,
                          transcribe_fn=transcribe, split=split_audio,
                          chunk_s: int = CHUNK_S) -> Transcript:
    parts = await split(audio, work_dir / "parts", chunk_s)
    segments, words, langs = [], [], []
    for i, part in enumerate(parts):
        t = await transcribe_fn(part, groq_key, http)
        off = i * chunk_s
        segments += [{**s, "start": s["start"] + off, "end": s["end"] + off}
                     for s in t.segments]
        part_words = t.words or words_from_segments(t.segments)
        words += [{**w, "start": w["start"] + off, "end": w["end"] + off} for w in part_words]
        if t.language:
            langs.append(t.language)
    language = Counter(langs).most_common(1)[0][0] if langs else None
    return Transcript(segments, language, words)


def dump_transcript(t: Transcript, path: Path) -> None:
    path.write_text(json.dumps({"segments": t.segments, "language": t.language,
                                "words": t.words}, ensure_ascii=False), encoding="utf-8")


def load_transcript(path: Path) -> Transcript:
    d = json.loads(path.read_text(encoding="utf-8"))
    return Transcript(d["segments"], d["language"], d["words"])
```

```python
"""Sinais de interesse, 1 ponto por segundo: volume, "mais repetidos" e chat."""
from __future__ import annotations

from pathlib import Path

import numpy as np

from ..processing.ffmpeg import run

WEIGHTS = {"heatmap": 0.45, "chat": 0.35, "loudness": 0.20}
AGREEMENT_BONUS = 0.15
SAMPLE_RATE = 8000


def robust_norm(x: np.ndarray, low_q: float = 25, high_q: float = 99) -> np.ndarray:
    if x.size == 0:
        return x.astype(float)
    lo, hi = np.percentile(x, low_q), np.percentile(x, high_q)
    return np.clip((x - lo) / max(hi - lo, 1e-9), 0.0, 1.0)


def moving_average(x: np.ndarray, w: int) -> np.ndarray:
    x = np.asarray(x, dtype=float)
    if w <= 1 or x.size == 0:
        return x
    return np.convolve(x, np.ones(w) / w, mode="same")


def loudness_signal(rms_db: np.ndarray) -> np.ndarray:
    """Quanto o volume sobe acima da média do último minuto (risada, grito, aplauso)."""
    baseline = moving_average(rms_db, 61)
    return robust_norm(np.maximum(rms_db - baseline, 0.0))


def heatmap_signal(heatmap: list[dict] | None, n: int) -> np.ndarray | None:
    pts = []
    for item in heatmap or []:
        try:
            pts.append(((float(item["start_time"]) + float(item["end_time"])) / 2,
                        float(item["value"])))
        except (KeyError, TypeError, ValueError):
            continue
    if len(pts) < 2:
        return None
    pts.sort()
    xs, ys = np.array([p[0] for p in pts]), np.array([p[1] for p in pts])
    return robust_norm(np.interp(np.arange(n) + 0.5, xs, ys))


def chat_signal(times: list[float], n: int) -> np.ndarray | None:
    if not times or n <= 0:
        return None
    idx = np.clip(np.asarray(times, dtype=int), 0, n - 1)
    counts = np.bincount(idx, minlength=n).astype(float)
    return robust_norm(moving_average(counts, 5))


def combine(signals: dict[str, np.ndarray | None]) -> np.ndarray:
    present = {k: v for k, v in signals.items() if v is not None and v.size}
    if not present:
        return np.zeros(0)
    n = min(v.size for v in present.values())
    total = sum(WEIGHTS[k] for k in present)
    score = sum(WEIGHTS[k] / total * present[k][:n] for k in present)
    agree = sum((present[k][:n] > 0.5).astype(int) for k in present)
    return score + AGREEMENT_BONUS * (agree >= 2)


async def rms_db_per_second(audio: Path, work_dir: Path, run=run) -> np.ndarray:
    raw = work_dir / "audio.raw"
    await run("ffmpeg", "-y", "-i", str(audio), "-f", "s16le", "-ac", "1",
              "-ar", str(SAMPLE_RATE), str(raw), timeout=1800)
    samples = np.fromfile(raw, dtype=np.int16).astype(np.float32)
    raw.unlink(missing_ok=True)
    n = samples.size // SAMPLE_RATE
    if n == 0:
        return np.zeros(0)
    per_sec = samples[: n * SAMPLE_RATE].reshape(n, SAMPLE_RATE)
    rms = np.sqrt((per_sec ** 2).mean(axis=1))
    return 20 * np.log10(rms / 32768 + 1e-9)
```

```python
"""Escolha dos picos da curva de interesse."""
from __future__ import annotations

import numpy as np

from .signals import moving_average


def pick_peaks(score: np.ndarray, max_peaks: int = 20, min_separation: int = 90,
               smooth: int = 5) -> list[int]:
    s = moving_average(np.asarray(score, dtype=float), smooth)
    picked: list[int] = []
    for i in np.argsort(-s, kind="stable"):
        if s[i] <= 0 or len(picked) >= max_peaks:
            break
        if all(abs(int(i) - j) >= min_separation for j in picked):
            picked.append(int(i))
    return sorted(picked)
```

```python
"""Bordas do corte: começa e termina em frase/pausa, nunca no meio de uma palavra."""
from __future__ import annotations

import numpy as np

PAUSE = 0.5
MIN_PRE_ROLL = 6.0
MIN_POST_ROLL = 3.0
SEARCH = 8.0
MAX_LEN = 65.0
MIN_LEN = 15.0
REACTION_MAX = 6.0


def ends_sentence(word: str) -> bool:
    w = word.strip()
    return bool(w) and w[-1] in ".?!" and not w.endswith("...") and not w.endswith("…")


def _boundary_after(words: list[dict], i: int) -> bool:
    """Depois da palavra i termina uma frase (pontuação ou pausa)."""
    if i == len(words) - 1:
        return True
    return ends_sentence(words[i]["word"]) or words[i + 1]["start"] - words[i]["end"] >= PAUSE


def sentence_starts(words: list[dict]) -> list[float]:
    if not words:
        return []
    return [words[0]["start"]] + [words[i]["start"] for i in range(1, len(words))
                                  if _boundary_after(words, i - 1)]


def sentence_ends(words: list[dict]) -> list[float]:
    return [w["end"] for i, w in enumerate(words) if _boundary_after(words, i)]


def sentences(words: list[dict]) -> list[tuple[float, float, str]]:
    out, cur = [], []
    for i, w in enumerate(words):
        cur.append(w)
        if _boundary_after(words, i):
            out.append((cur[0]["start"], cur[-1]["end"],
                        " ".join(x["word"].strip() for x in cur)))
            cur = []
    return out


def _nearest(cands: list[float], target: float, lo: float, hi: float) -> float | None:
    inside = [c for c in cands if lo <= c <= hi]
    return min(inside, key=lambda c: abs(c - target)) if inside else None


def extend_past_reaction(end: float, words: list[dict], rms_db: np.ndarray | None) -> float:
    """Não corta a risada: estende enquanto o volume fica 3 dB acima da base local,
    até 6 s e sem invadir a próxima palavra."""
    if rms_db is None or rms_db.size == 0:
        return end
    next_start = next((w["start"] for w in words if w["start"] > end + 0.01),
                      end + REACTION_MAX)
    limit = min(end + REACTION_MAX, next_start - 0.05, float(rms_db.size))
    i0 = int(end)
    base = float(np.median(rms_db[max(0, i0 - 45): i0 + 45]))
    t = end
    sec = i0
    while sec < limit and sec < rms_db.size and rms_db[sec] > base + 3:
        t = min(limit, sec + 1.0)
        sec += 1
    return max(end, t)


def snap_clip(words: list[dict], peak: float, start: float, end: float,
              rms_db: np.ndarray | None = None) -> tuple[float, float] | None:
    if not words:
        return None
    starts, ends = sentence_starts(words), sentence_ends(words)
    s_hi, e_lo = peak - MIN_PRE_ROLL, peak + MIN_POST_ROLL
    s = _nearest(starts, start, start - SEARCH, min(start + SEARCH, s_hi))
    if s is None:
        s = _nearest([w["start"] for w in words], start, start - SEARCH, s_hi)
    e = _nearest(ends, end, max(end - SEARCH, e_lo), end + SEARCH)
    if e is None:
        e = _nearest([w["end"] for w in words], end, e_lo, end + SEARCH)
    if s is None or e is None:
        return None
    if e - s > MAX_LEN:  # o maior trecho ≤ 65 s que ainda contém o pico
        pairs = [(a, b) for a in starts if s <= a <= s_hi
                 for b in ends if e_lo <= b <= e and b - a <= MAX_LEN]
        if not pairs:
            return None
        s, e = max(pairs, key=lambda p: p[1] - p[0])
    e = min(extend_past_reaction(e, words, rms_db), s + MAX_LEN)
    if e - s < MIN_LEN:
        return None
    return round(s, 2), round(e, 2)
```

> Se `extend_past_reaction` for cortado por `s + MAX_LEN`, o fim cai num trecho sem fala (a
> extensão nunca passa da próxima palavra), então continua sem cortar palavra.

```python
"""A IA lê a transcrição em volta de cada pico e decide onde começa e termina o assunto."""
from __future__ import annotations

from dataclasses import dataclass

from pydantic import BaseModel

from ..ai.text import ask_json
from .snap import MIN_POST_ROLL, MIN_PRE_ROLL, sentences

WINDOW_BEFORE = 150
WINDOW_AFTER = 90

TOPICS_PROMPT = """Você é editor de cortes de um perfil brasileiro de clipes (Reels, TikTok, Shorts).
Abaixo estão trechos da transcrição de um vídeo, um por PICO de interesse (risada, chat
explodindo, parte mais repetida pelo público). Cada linha começa com o tempo [m:ss].

Para CADA pico, decida se ali tem um corte que prende quem rola o feed:
- manter=true só se houver um momento claro (história engraçada, treta, revelação, reação
  forte, frase marcante) que se entende sem o resto do vídeo;
- inicio e fim em SEGUNDOS desde o começo do vídeo, cobrindo o ASSUNTO COMPLETO (de ~20 s a
  ~3 min): comece onde o assunto começa e termine depois do desfecho/reação;
- motivo: 1 frase.
Responda só o JSON pedido, com um item por pico (campo "pico" = número do pico).

Vídeo: {title}
Instrução do admin: {instructions}"""


class TopicCut(BaseModel):
    pico: int
    manter: bool
    inicio: float
    fim: float
    motivo: str


class TopicsAnswer(BaseModel):
    cortes: list[TopicCut]


@dataclass
class Topic:
    peak: float
    start: float
    end: float
    why: str


def fmt_time(t: float) -> str:
    m, s = divmod(int(t), 60)
    h, m = divmod(m, 60)
    return f"{h}:{m:02d}:{s:02d}" if h else f"{m}:{s:02d}"


def build_topics_prompt(title: str, words: list[dict], peaks: list[int],
                        instructions: str) -> str:
    sents = sentences(words)
    blocks = []
    for k, p in enumerate(peaks):
        lo, hi = p - WINDOW_BEFORE, p + WINDOW_AFTER
        lines = [f"[{fmt_time(a)}] {txt}" for a, b, txt in sents if b >= lo and a <= hi]
        blocks.append(f"### Pico {k} (em {fmt_time(p)})\n" + ("\n".join(lines) or "(sem fala)"))
    head = TOPICS_PROMPT.format(title=title or "(sem título)",
                                instructions=instructions.strip() or "(nenhuma)")
    return head + "\n\n" + "\n\n".join(blocks)


def parse_topics(answer: TopicsAnswer, peaks: list[int]) -> list[Topic]:
    chosen = []
    for c in answer.cortes:
        if not c.manter or not 0 <= c.pico < len(peaks) or c.fim <= c.inicio:
            continue
        peak = min(max(float(peaks[c.pico]), c.inicio + MIN_PRE_ROLL), c.fim - MIN_POST_ROLL)
        chosen.append(Topic(peak, float(c.inicio), float(c.fim), c.motivo))
    chosen.sort(key=lambda t: t.start)
    merged: list[Topic] = []
    for t in chosen:  # picos no mesmo assunto viram um corte só
        if merged and t.start < merged[-1].end:
            merged[-1].end = max(merged[-1].end, t.end)
        else:
            merged.append(t)
    return merged


async def choose_topics(cfg, title: str, words: list[dict], peaks: list[int],
                        instructions: str, ask=ask_json, db=None) -> list[Topic]:
    if not peaks:
        return []
    answer = await ask(cfg, build_topics_prompt(title, words, peaks, instructions),
                       TopicsAnswer, db=db)
    return parse_topics(answer, peaks)
```

```python
"""Fila do sob demanda: um vídeo por vez, em etapas que sobrevivem a um reinício."""
from __future__ import annotations

import asyncio
import json
import logging
import shutil
from dataclasses import asdict, dataclass, field
from datetime import timedelta
from pathlib import Path
from typing import Protocol

import numpy as np

from ..ai.evaluator import AIUnavailable
from ..core.models import Candidate, State
from ..core.timeutil import parse_iso, utcnow
from ..processing.ffmpeg import probe_dimensions
from ..processing.subtitles import build_cues, cues_to_ass
from . import ingest, longtranscribe, signals
from .peaks import pick_peaks
from .snap import snap_clip
from .topics import Topic, choose_topics

log = logging.getLogger(__name__)

DONE_STATES = {State.AWAITING_APPROVAL, State.APPROVED, State.PUBLISHED, State.DISCARDED}


class JobNotifier(Protocol):
    async def progress(self, job: dict, text: str) -> None: ...
    async def finished(self, job: dict, ok: bool, text: str) -> None: ...


class LogJobNotifier:
    async def progress(self, job, text):
        log.info("[sob demanda #%s] %s", job["id"], text)

    async def finished(self, job, ok, text):
        log.info("[sob demanda #%s] %s %s", job["id"], "✅" if ok else "❌", text)


@dataclass
class OnDemandOps:
    probe: object = ingest.probe
    download_audio: object = ingest.download_audio
    download_section: object = ingest.download_section
    fetch_chat: object = ingest.fetch_youtube_chat
    transcribe: object = None  # ligado no __init__ do runner (precisa da chave do Groq)
    rms: object = signals.rms_db_per_second
    topics: object = choose_topics
    probe_dims: object = probe_dimensions


class JobFailed(Exception):
    """Falha que vira ❌ com o motivo na thread."""


class OnDemandRunner:
    def __init__(self, db, cfg, http, jobs_dir: Path, media_dir: Path, notifier,
                 ops: OnDemandOps | None = None, now_fn=utcnow, ai_retry_s: float = 300):
        self.db = db
        self.cfg = cfg
        self.http = http
        self.jobs_dir = jobs_dir
        self.media_dir = media_dir
        self.notifier = notifier
        self.ops = ops or OnDemandOps()
        if self.ops.transcribe is None:
            async def _transcribe(audio, key, http, work):
                return await longtranscribe.transcribe_long(audio, key, http, work)
            self.ops.transcribe = _transcribe
        self.now_fn = now_fn
        self.ai_retry_s = ai_retry_s

    # --- fila ---------------------------------------------------------------
    def enqueue(self, url: str, instructions: str, channel_id, message_id) -> int:
        return self.db.create_job(url, instructions[:500], channel_id, message_id)

    def queue_position(self, job_id: int) -> int:
        queued = [j["id"] for j in self.db.jobs_in(["queued"])]
        return queued.index(job_id) + 1 if job_id in queued else 0

    def status_line(self) -> str:
        running = self.db.jobs_in(["running"])
        waiting = len(self.db.jobs_in(["queued"]))
        if not running:
            return "🔗 Sob demanda: livre" + (f" · {waiting} na fila" if waiting else "")
        j = running[0]
        return (f'🔗 Sob demanda: processando "{j["title"] or j["url"]}" '
                f'({j["progress"] or "começando"}) · {waiting} na fila')

    def requeue_waiting(self) -> None:
        limit = self.now_fn() - timedelta(seconds=self.ai_retry_s)
        for j in self.db.jobs_in(["waiting_ai"]):
            if parse_iso(j["updated_at"]) <= limit:
                self.db.update_job(j["id"], state="queued")

    # --- etapas -------------------------------------------------------------
    async def _progress(self, job: dict, step: str, text: str) -> None:
        self.db.update_job(job["id"], step=step, progress=text)
        job = self.db.get_job(job["id"])
        try:
            await self.notifier.progress(job, text)
        except Exception as e:
            log.warning("progresso do job %s não enviado: %s", job["id"], e)

    async def _finish(self, job: dict, ok: bool, text: str, state: str) -> None:
        self.db.update_job(job["id"], state=state, progress=text,
                           error=None if ok else text[:500])
        shutil.rmtree(self.jobs_dir / str(job["id"]), ignore_errors=True)
        try:
            await self.notifier.finished(self.db.get_job(job["id"]), ok, text)
        except Exception as e:
            log.warning("fim do job %s não enviado: %s", job["id"], e)

    async def process(self, job: dict) -> None:
        jid = job["id"]
        work = self.jobs_dir / str(jid)
        work.mkdir(parents=True, exist_ok=True)
        self.db.update_job(jid, state="running")
        try:
            meta = await self._meta(job, work)
            audio = await self._audio(job, work, meta)
            transcript = await self._transcript(job, work, audio)
            if not transcript.words:
                await self._finish(job, True, "nenhuma fala encontrada no vídeo", "done")
                return
            score, rms = await self._signals(job, work, meta, audio)
            topics = await self._topics(job, work, meta, transcript, score)
            made = await self._cuts(job, meta, transcript, topics, rms)
        except AIUnavailable:
            self.db.update_job(jid, state="waiting_ai", progress="aguardando a IA voltar…")
            await self._progress(self.db.get_job(jid), "topics", "⏸️ aguardando a IA voltar…")
            return
        except JobFailed as e:
            await self._finish(job, False, str(e), "failed")
            return
        except Exception as e:
            log.exception("job %s falhou", jid)
            await self._finish(job, False, f"erro: {str(e)[:300]}", "failed")
            return
        if made == 0:
            await self._finish(job, True, "nenhum momento forte encontrado neste vídeo", "done")
            return
        self.db.update_job(jid, state="evaluating")
        await self._progress(self.db.get_job(jid), "evaluating",
                             f"🧠 a IA está avaliando {made} corte(s)…")

    async def _meta(self, job, work):
        path = work / "meta.json"
        if path.exists():
            return ingest.VideoMeta(**json.loads(path.read_text(encoding="utf-8")))
        await self._progress(job, "meta", "🔎 lendo o vídeo…")
        meta = await self.ops.probe(job["url"])
        if meta.is_live:
            raise JobFailed("live em andamento ainda não é suportada (V2.1)")
        if meta.duration > self.cfg.ondemand_max_hours * 3600:
            raise JobFailed(f"vídeo longo demais (máximo {self.cfg.ondemand_max_hours:g} h)")
        path.write_text(json.dumps(asdict(meta), ensure_ascii=False), encoding="utf-8")
        self.db.update_job(job["id"], title=meta.title[:200])
        return meta

    async def _audio(self, job, work, meta):
        path = work / "audio.mp3"
        if not path.exists():
            await self._progress(job, "audio", "⬇️ baixando o áudio…")
            path = await self.ops.download_audio(job["url"], path)
        return path

    async def _transcript(self, job, work, audio):
        path = work / "transcript.json"
        if path.exists():
            return longtranscribe.load_transcript(path)
        await self._progress(job, "transcript", "📝 transcrevendo…")
        t = await self.ops.transcribe(audio, self.cfg.groq_api_key, self.http, work)
        longtranscribe.dump_transcript(t, path)
        return t

    async def _signals(self, job, work, meta, audio):
        score_path, rms_path = work / "score.npy", work / "rms.npy"
        if score_path.exists() and rms_path.exists():
            return np.load(score_path), np.load(rms_path)
        await self._progress(job, "signals",
                             "📈 procurando os picos (volume, mais repetidos, chat)…")
        rms = await self.ops.rms(audio, work)
        n = max(rms.size, int(meta.duration))
        chat = await self.ops.fetch_chat(job["url"], work) if meta.platform == "youtube" else []
        score = signals.combine({
            "loudness": signals.loudness_signal(rms) if rms.size else None,
            "heatmap": signals.heatmap_signal(meta.heatmap, n),
            "chat": signals.chat_signal(chat, n),
        })
        np.save(score_path, score)
        np.save(rms_path, rms)
        return score, rms

    async def _topics(self, job, work, meta, transcript, score) -> list[Topic]:
        path = work / "topics.json"
        if path.exists():
            return [Topic(**t) for t in json.loads(path.read_text(encoding="utf-8"))]
        await self._progress(job, "topics", "🤖 a IA está escolhendo os momentos…")
        peaks = pick_peaks(score)
        topics = await self.ops.topics(self.cfg, meta.title, transcript.words, peaks,
                                       job["instructions"], db=self.db)
        path.write_text(json.dumps([asdict(t) for t in topics]), encoding="utf-8")
        return topics

    async def _cuts(self, job, meta, transcript, topics, rms) -> int:
        existing = {c.clip_id for c in self.db.job_candidates(job["id"])}
        clips = [c for c in (snap_clip(transcript.words, t.peak, t.start, t.end, rms)
                             for t in topics) if c is not None]
        made = len(existing)
        for i, (s, e) in enumerate(clips, 1):
            clip_id = f"ondemand:{job['id']}:{int(s * 10)}"
            if clip_id in existing:
                continue
            await self._progress(job, "cuts", f"✂️ recortando {i}/{len(clips)}…")
            try:
                await self._make_candidate(job, meta, transcript, clip_id, s, e)
                made += 1
            except Exception as ex:
                log.warning("corte %s do job %s falhou: %s", i, job["id"], ex)
        return made

    async def _make_candidate(self, job, meta, transcript, clip_id, s, e) -> None:
        c = Candidate(platform=meta.platform if meta.platform != "outro" else "youtube",
                      source="ondemand", clip_id=clip_id, clip_url=job["url"],
                      channel=meta.channel, created_at=self.now_fn(), duration=e - s,
                      title=meta.title, rank=1000.0, state=State.FAILED,
                      reason="recortando (sob demanda)", job_id=job["id"],
                      start_s=s, end_s=e)
        if self.db.insert_candidate(c) is None:
            return  # já existia
        folder = self.media_dir / str(c.id)
        raw = await self.ops.download_section(job["url"], s, e, folder / "raw.mp4")
        words = [{**w, "start": w["start"] - s, "end": w["end"] - s}
                 for w in transcript.words if w["start"] >= s and w["end"] <= e]
        cues = build_cues(words)
        if cues:
            w, h = await self.ops.probe_dims(raw)
            (folder / "subs.ass").write_text(cues_to_ass(cues, w, h), encoding="utf-8")
        c.raw_path = str(raw)
        c.transcript = " ".join(x["word"].strip() for x in words)
        c.state, c.reason = State.DETECTED, None
        self.db.update(c)

    async def check_evaluating(self) -> None:
        for job in self.db.jobs_in(["evaluating"]):
            cands = self.db.job_candidates(job["id"])
            if any(c.state in (State.DETECTED, State.PROCESSING) for c in cands):
                continue
            sent = [c for c in cands if c.state in DONE_STATES]
            rejected = sorted((c for c in cands if c.state is State.REJECTED_AI),
                              key=lambda c: c.ai_score or 0, reverse=True)
            text = (f"{len(sent)} corte(s) enviado(s) para o #aprovação, "
                    f"{len(rejected)} descartado(s) pela IA")
            if not sent and rejected:
                text = "nenhum corte passou da nota mínima. Os melhores descartados:\n" + \
                    "\n".join(f"• {c.ai_score or 0:.1f} — {c.reason}" for c in rejected[:3])
            await self._finish(job, True, text, "done")

    async def run(self) -> None:
        self.db.reset_running_jobs()
        while True:
            try:
                self.requeue_waiting()
                await self.check_evaluating()
                job = self.db.next_job()
                if job is not None:
                    await self.process(job)
                    continue
            except asyncio.CancelledError:
                raise
            except Exception:
                log.exception("fila do sob demanda")
            await asyncio.sleep(5)
```

```python
URL_RE = re.compile(r"https?://\S+")


def parse_link_message(text: str) -> tuple[str, str] | None:
    m = URL_RE.search(text or "")
    if not m:

    rest = (text[:m.start()] + " " + text[m.end():]).strip()
```

```python
class DiscordJobNotifier:
    """Progresso do sob demanda na thread da mensagem original."""

    def __init__(self, bot: DiscordBot):
        self.bot = bot
        self._last: dict[int, str] = {}

    async def _channel(self, channel_id):
        return self.bot.client.get_channel(channel_id) or \
            await self.bot.client.fetch_channel(channel_id)

    async def progress(self, job, text):
        if not job.get("thread_id") or not job.get("status_message_id"):
            return
        if self._last.get(job["id"]) == text:
            return
        await asyncio.wait_for(self.bot._ready.wait(), timeout=120)
        thread = await self._channel(job["thread_id"])
        msg = await thread.fetch_message(job["status_message_id"])
        await msg.edit(content=text[:2000])
        self._last[job["id"]] = text

    async def finished(self, job, ok, text):
        await self.progress(job, ("✅ " if ok else "❌ ") + text)
        if job.get("channel_id") and job.get("message_id"):
            channel = await self._channel(job["channel_id"])
            msg = await channel.fetch_message(job["message_id"])
            try:
                await msg.remove_reaction("⏳", self.bot.client.user)
            except discord.HTTPException:
                pass
            await msg.add_reaction("✅" if ok else "❌")
        self._last.pop(job["id"], None)
```
